    CSM learning objectives

    Tick each objective after you have covered it. Wording follows the Scrum Alliance list (updated January 2022); check the current version before you teach.

    Theme, planning process and mission

    Pick a theme and it loads that service's usual planning process and a starter mission. You can then change either one on its own, so a Navy theme can run an Army mission under MCPP.

    Changing the mission or the process rebuilds that one board only. Your other boards are not touched. All missions are fictional and unclassified.

    Work roles

    Change the name and the sticky-note color for each role. Role names appear in the Roles sort board and on notes.
